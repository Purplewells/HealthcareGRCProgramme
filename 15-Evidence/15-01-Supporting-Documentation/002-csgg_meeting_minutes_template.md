# Cyber Security Governance Group — Meeting Minutes (Template)

**Organisation:** Westbridge Hospitals Trust (WHT)
**Document Type:** Template
**Owner:** CISO (Chief Information Security Officer)
**Version:** 1.0

## Purpose

This is a blank template, not a completed record of any meeting. It exists so the Cyber Security Governance Group's (CSGG) standing agenda — set out in [../../05-Governance/052-roles_and_responsibilities.md](../../05-Governance/052-roles_and_responsibilities.md) §3 — has a consistent minute-taking structure, and so the recurring reporting items referenced across the programme (risk register review, roadmap progress, dashboard review) are captured the same way meeting to meeting. It is a process artefact, not evidence that a specific meeting occurred — see the distinction drawn in [README](README.md).

## 2. Risk Register Review

## 3. Roadmap and Improvement Plan Progress
