# Screenshots

This folder is for genuine tool-output screenshots that support a specific finding elsewhere in the programme — for example, an Azure Secure Score results page backing [123-secure_score_review](../../12-Azure-Governance/123-secure_score_review.md), a Conditional Access sign-in log confirming a policy is working as described in [122-conditional_access_policies](../../12-Azure-Governance/122-conditional_access_policies.md), or a vulnerability scanner result backing an entry in [091-vulnerability_register](../../09-Security-Operations/091-vulnerability_register.md).

No screenshots are included in this portfolio case study. Fabricating screenshots of product interfaces (Azure Portal, a scanning tool, etc.) would present invented tool output as if it were a real, captured screen — a different kind of artifact from the narrative documents elsewhere in this programme, which are explicitly framed as a fictional case study rather than as evidence of a real system's state. If this programme is adapted for a real engagement, screenshots should be added here named as `<source-document-id>_<short-description>.png` (e.g. `123_secure_score_baseline.png`) and referenced from the document they support, in the same way diagrams are referenced from [../15-02-Diagrams/README.md](../15-02-Diagrams/README.md).
